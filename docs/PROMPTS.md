# PROMPTS.md — paste-ready prompts for lanes B, C, D (starting from zero)

How to use: open a terminal in any empty folder (for example `mkdir -p ~/sundai && cd ~/sundai`), start Claude Code there, paste your lane's whole block as the first message. Claude clones the repo, checks out your branch, verifies the setup, then builds. If Claude asks a question, answer it; if it says it is blocked, ping the integrator (lane A).
